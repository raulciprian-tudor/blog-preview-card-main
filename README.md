# Blog Preview Card

![Design preview for the Blog preview card coding challenge](./preview.jpg)

A small blog preview card built with HTML and CSS. It shows a category tag, a publish date, a title, a short excerpt, and the author's name and avatar, styled as a single card on a yellow background.

## How it's built

- Semantic HTML5 markup
- CSS Flexbox for layout
- Native CSS nesting for styles
- [Figtree](https://fonts.google.com/specimen/Figtree) variable font

## Files

- [index.html](index.html) - page markup
- [styles.css](styles.css) - styles
- [assets/](assets/) - fonts and images used by the card

## Running it

Open [index.html](index.html) directly in a browser, or serve the folder with any static file server.
